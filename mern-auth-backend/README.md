# MERN Auth Backend (scaffold)

This project is a scaffold for a secure MERN backend with:
- Access & refresh token rotation
- HttpOnly refresh cookies
- Email verification, password reset
- Account lockout & rate limiting
- Audit logs & RBAC middleware
- Helmet & CORS

How to run:
1. Copy `.env.example` to `.env` and fill values.
2. `npm install`
3. `npm run dev` (requires nodemon) or `npm start`

See earlier assistant messages for curl examples and security notes.
